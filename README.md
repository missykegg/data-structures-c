# Data Structures & Algorithms in C

A collection of foundational data structures implemented in ANSI C (C99) with memory leak safety and unit test coverage.

## 🗂 Implemented Structures
- **Vector**: Dynamically resizing array with amortized O(1) appending.
- **Linked List**: Singly and doubly linked lists with insertion, deletion, and reverse operations.
- **Hash Table**: Open addressing hash map with MurmurHash / DJB2 hashing.
- **Binary Search Tree**: Self-balancing BST traversal and search.
